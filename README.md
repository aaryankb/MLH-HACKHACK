## 1. Project Overview & Humane Vision

In emergency medical field clinics, disaster relief camps, and humanitarian rescue operations, communication breakdowns can be fatal. Standard translation tools often fail in two critical ways:
1. They require constant internet connectivity, which is frequently unavailable in remote or crisis areas.
2. They produce literal, ambiguous, or inaccurate translations for life-critical domain terminology (e.g. mistranslating *"anaphylaxis"* or *"potable water"*).

**Hybrid AI Translation App** solves this with a **humane, face-to-face Native Android application**:
- **Face-to-Face Split Screen UI:** The top half of the screen is rotated $180^\circ$ for the conversational partner sitting or standing across a table, while the bottom half is upright for the primary speaker.
- **Context Setter:** Users specify the operational domain (e.g. *"Emergency medical diagnosis"*, *"Disaster relief rations distribution"*, *"Legal refugee consultation"*).
- **Agent Skill Integration (`glossary-lookup`):** Strictly follows the **Agent Skills open standard** (`skill.json`). It dynamically pulls domain-specific vocabulary rules and canonical local translations before generation.
- **Custom Model Harness:** An original model harness that analyzes context, executes the agent skill, constructs structured system prompts, and routes requests between online cloud and offline edge engines.
- **Dual AI Engine:**
  - **Online Cloud (Gemma 4):** Calls Google Gemma 4 models via the official **Google Gemini API** (`com.google.ai.client.generativeai`).
  - **Offline Local Edge (Gemma 4 E2B):** Runs on-device inference using **Google MediaPipe LLM Inference** (`com.google.mediapipe:tasks-genai`) without internet access.

## 6. How the Project Uses Gemma 4 Through the Gemini API

For the **Best Use of Gemma 4** prize:
- The app uses the official Google Generative AI SDK (`com.google.ai.client.generativeai:generativeai`).
- Located in `app/src/main/java/com/moss/hybridtranslator/services/GeminiGemmaService.kt`.
- Targeted model: `gemma-4-it` (configurable in app settings).
- Prompts are generated by the custom model harness, incorporating conversation context, previous turn history, and agent skill terminology rules into the Gemma 4 system prompt.

## 7. Custom Agent Skill & Model Harness

For the **Best Open-Source AI Project** prize:

### Custom Agent Skill (`glossary-lookup`)
- **Directory:** `agent-skills/glossary-lookup/`
- **Standard:** Strictly conforms to the **Agent Skills open standard** with metadata and parameter specifications in [`skill.json`](agent-skills/glossary-lookup/skill.json) and documentation in [`SKILL.md`](agent-skills/glossary-lookup/SKILL.md).
- **Curated Multi-Lingual Datasets:** Included in `agent-skills/glossary-lookup/data/` for **Medical**, **Disaster Relief**, and **Legal** operations across English, Kannada (`kn`), Hindi (`hi`), Telugu (`te`), Tamil (`ta`), and Spanish (`es`).

### Custom Model Harness (`src/.../harness/ModelHarness.kt`)
- An original Kotlin model harness that manages:
  - Dynamic evaluation of the Context Setter.
  - Automatic tool invocation of `GlossaryLookupSkill`.
  - Conversation memory window (last 3 turns).
  - Strict system prompt assembly conforming to the specification in `plan.md`.
  - Seamless routing to MediaPipe on-device LLM Inference or Gemini Cloud.
  - Telemetry capture (latency, matched domain, active terms) for the interactive **Agent Skill Inspector**.

## 10. How to Build & Run

### Prerequisites
- JDK 17 (OpenJDK 17 recommended)
- Android SDK (API 34 or 35) or Android Studio Ladybug / Meerkat
- Physical Android device (recommended for speech & audio) or Android Emulator

### Steps

1. **Clone the repository:**
   ```bash
   git clone git@github.com:aaryankb/MLH-HACKHACK.git
   cd MLH-HACKHACK
   ```

2. **Run Unit Tests:**
   ```bash
   ./gradlew test
   ```

3. **Build the Debug APK:**
   ```bash
   ./gradlew assembleDebug
   ```
   The APK will be generated at `app/build/outputs/apk/debug/app-debug.apk`.

4. **Install on connected device:**
   ```bash
   ./gradlew installDebug
   ```

5. **Using the App:**
   - Place the phone on a table between two speakers.
   - User B sees the top half oriented right-side up for them ($180^\circ$ rotated).
   - Tap the **Context Setter** pill to choose a domain (e.g. *Medical* or *Disaster Relief*).
   - Press the **Microphone** button to speak, or type into the input field.
   - Tap the **Skill Inspector** button (`{;}`) on the center bar to inspect how the Agent Skill resolved terminology and injected the prompt.
   - Toggle between **Online (Gemma 4)** and **Offline (MediaPipe Gemma 4 E2B)** to experience edge resilience.
